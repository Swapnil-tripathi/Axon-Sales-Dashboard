# Axon-Sales-Dashboard
End-to-end Sales Analytics Dashboard built in Power BI using Excel, Power Query, and DAX. Includes KPI tracking, sales and profit analysis, customer insights, regional performance, interactive filters, and business-focused visualizations for informed decision-making.
**📊 Axon Sales Dashboard
Overview:**

This project is an interactive Sales Analytics Dashboard built using Power BI to analyze sales performance, customer behavior, profitability, and regional performance.

The dashboard enables business users to monitor KPIs, identify top-performing products and customers, and filter insights by category and year.

**Insights**
•	USA contributes the highest overall profit. 
•	EMEA generates the largest territory-wise profit. 
•	The highest-performing customer generated over ₹1M in sales. 
•	Weekend sales contribute a smaller share of overall revenue. 
•	A small group of products contributes a significant portion of total profit.
